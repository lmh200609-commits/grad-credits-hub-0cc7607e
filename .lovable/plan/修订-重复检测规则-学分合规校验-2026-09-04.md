# 修订：重复检测规则 + 学分合规校验

在已批准的「下载模板填表 → 表格+多张佐证提交 → 系统只验真伪」方案基础上，修正两处规则。其余部分（模板剔除样例、多图上传、教师端原图与班级筛选、学生端去关键词化）保持不变。

## 一、重复提交检测：不按「认定项目」拦截

学校《认定办法》第八条：同一项目或成果不得重复认定，只认定最高级奖项；**不同项目或作品参加同一比赛（含不同年份不同届）可累计获得学分**。所以按项目名拦截是错的——"学科竞赛/国家级B类""发表论文"这类项目名本来就会反复出现。

新规则（只保留两条硬拦截）：

1. **同一张佐证图片**（`file_hash` 相同，全平台唯一）→ 拦截，提示"该图片已被提交过"。
2. **同一学生 + 同一「成果名称 + 认定级别」且已审核通过** → 拦截，提示"该成果已认定通过，同一成果只认定最高级别"。
   - 指纹改为 `normalize(成果名称) + '|' + normalize(认定级别)`，**不含认定项目、不含大类**。
   - 成果名称不同 → 一律放行，哪怕项目、级别、学分完全一样。

3. **不做拦截、只做提示**的情况：同一成果名称但级别不同（可能是升级奖项）→ 放行，在教师端提示"该学生此前已认定过同名成果（级别 X），请确认是否只认定最高级别"。

真正的拦截重心转到**内容核验**：佐证材料上的姓名 / 学号 / 成果名称 / 级别 / 排名与表格填报不符时判为不通过。

## 二、新增：自报学分合规校验（对照《认定办法》附件标准）

把《认定办法》附件的四类学分标准固化为标准表 `src/lib/creditStandard.ts`，逐条比对学生自报学分：

- **教学科研**：SCI/SSCI/CSSCI（一作 10 / 其他 8）；EI/CPCI/北大核心（8 / 6）；国家级、省级普刊报刊（6 / 4）；省级以上科研纵向项目等（主持 10 / 参与 8）；市级以上等（8 / 6）；省级以上学会项目（4 / 2）；科学调查研究（2 / 1）；知识产权（第一署名 6 / 其他 4）
- **创新创业**：大创国家级（6/5/4）、省级（5/4/2）、校级（2/1）；自主创业（负责人 4 / 成员 2）；互联网+ 与挑战杯国赛一/二/三等（10-9-8 / 8-7-6 / 6-5-4）、省赛（8-7-6 / 6-5-4 / 5-4-3）
- **学科竞赛**：国家级B类 一/二/三等（8-7-6 / 7-6-5 / 5-4）；省部级A类（6-5 / 5-4 / 4-3）；省部级B类（6-4 / 5-4 / 4-2）；校级（5-4 / 4-2 / 2-1）
- **职业技能**：CET-6=6、CET-4=4；专八=6、专四=4；计算机等级/职业资格 高级 6、中级 4、初级 2；其他行业认证 2；第二课堂每 16 学时或 1 周记 1 学分
- **总分规则**：在校期间不得低于 4 学分；成绩等级 ≥7 优秀、6 良好、5 中等、4 及格、<4 不及格
- **第二课堂**：属于"职业技能"大类下的认定项目（《认定办法》表四第 5 项），每 16 学时或 1 周记 1 学分，凭学校/学院出具的活动参与证明认定，模板中归"四、职业技能"填写

等级与统计展示：

- `src/lib/creditStandard.ts` 附带 `gradeOf(totalCredit)`：`≥7 优秀 / 6 良好 / 5 中等 / 4 及格 / <4 不及格`。
- 教师端学生列表与学分统计页：每个学生累计认定学分旁显示等级徽标（优秀/良好/中等/及格/不及格）。
- 学院统计表导出：新增"累计学分""成绩等级"两列，与《认定办法》第十二条的成绩统计表口径一致。

校验方式与展示：

- 提交时（学生端）：解析出每条后即时比对，超标条目黄色提示「你填 8 分，按标准应为 6 分」，**不阻止提交**（最终以教师认定为准），但会记录。
- AI 核验时：以佐证材料上识别到的真实级别/排名去查标准表，若与自报学分不符，写入不合规原因。
- 教师端：不合规条目红色标注「自报 X 分 / 标准 Y 分（依据：类别-项目-成果-排名）」，教师点一下即可把认定学分改为标准值。

## 三、技术说明（相对原方案的增量）

- `applications` 再加两列（一条迁移）：`credit_standard`（numeric，标准学分）、`credit_compliance`（text：`ok` / `over` / `under` / `unknown`）。
- 新增 `src/lib/creditStandard.ts`：标准表 + `lookupStandardCredit({category, project, achievement, level, rank})` → `{ credit, matched, basis }`；匹配用「级别关键词 + 排名关键词」双维度模糊匹配，匹配不到返回 `unknown`（不误报）。
- 重复检测：`src/lib/keywordFingerprint.ts` 改为 `buildAchievementFingerprint(成果名称, 认定级别)`；同步更新数据库 `applications_dedupe_guard` 的中文报错文案。
- `evaluate-application` 增加一项输出 `credit_compliance_note`，与既有核验项并列，不影响其他链路。
- 教师端在既有「学生自报学分 / 教师认定学分」旁增加「标准学分」与一键采用按钮。
