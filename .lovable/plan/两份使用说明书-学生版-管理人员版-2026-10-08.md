# 两份使用说明书（学生版 + 管理人员版）

## 交付物
- `学生使用说明书.docx`：给学生看，**不出现任何 AI、自动核对、人工复核之类的字样**
- `管理人员使用说明书.docx`：给超级管理员、学院管理员、教师看
- 两份都用 Word 格式（方便打印、修改和转 PDF），配真实系统截图，截图上用红框和序号标出要点击的位置，旁边配文字说明
- 文字通俗：按「我想做什么 → 点哪里 → 会看到什么」来写，每章开头有一张简单的流程图

## 学生版目录
1. 系统简介、登录（账号就是学号，首次登录的默认密码）
2. 首次登录：完善个人信息（姓名、班级、专业、身份证号、性别）
3. 工作台
4. 提交申请：下载模板和示例表 → 填表 → 上传申请表 → 添加佐证图片 → 提交（附注意事项：只能在开放批次内提交、同一张图片不能重复用、学分超标只提醒不拦截、上传时不要关闭页面）
5. 我的申请：状态说明（待核对 / 已通过 / 未通过），查看详情
6. 我的档案、修改密码、退出登录
7. 常见问题

## 管理人员版目录
1. 角色说明：超级管理员、学院管理员、教师各自能做什么（列成一张表）
2. 登录与修改密码
3. 教师：工作台、审核申请（申请详情、通过/驳回、查看核对结果）、提交记录、学生管理（资料未完善标记、重置密码）、班级、学分统计
4. 学院管理员：数据看板、用户管理（学生/教师）、批量导入、提交批次（开放时间、批次报告）、材料导出（压缩包的目录结构）、认定规则、关键词、案例库、赛事名录、证书名录、学分汇总、操作日志、学院外观设置
5. 超级管理员：学院管理、学院管理员账号、AI 模型配置、AI 生成图鉴别设置、数据重置（附风险提醒）
6. 一次完整审核流程：开批次 → 学生提交 → 系统核对 → 教师审核 → 导出归档
7. 常见问题

## 截图怎么拿
- 临时建学生、教师、学院管理员三个测试账号，再建一个测试批次和 1～2 份示例申请，用来截各个页面
- 超级管理员的页面用一个临时超管账号来截
- 截完立即删除所有临时账号、批次、申请和文件，和上次测试一样清理干净
- 截图中的姓名、学号都使用明显的示例数据

## 检查
- 把两份文档逐页转成图片检查：排版、截图清晰度、标注位置、有没有错别字
- 学生版全文搜索「AI」「人工」「复核」「智能」等字样，确保一个都没有

## 技术细节
- 截图：Playwright（1280 宽），用 PIL 加红框和序号
- 文档：python-docx 生成，中文字体用微软雅黑/宋体，A4 纸，带目录
- 输出到 /mnt/documents/
