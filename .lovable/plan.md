# 文案清理 + 模板与统计表更新

## 1. 首页「申请学分」入口的旧描述
卡片副标题仍是上一版的「通过关键词匹配规则，一键提交进入审核流程。」
改为：「下载模板填表，上传申请表与佐证材料即可提交。」

## 2. 学生端不暴露"系统核验/AI"
提交申请页两处提示：
- 副标题「下载模板填表 → 上传申请表与佐证材料 → 系统核验真伪」→「下载模板填表 → 上传申请表与佐证材料 → 提交审核」
- 第 3 步「提交系统核验 / 只验真伪，学分以教师认定为准」→「提交申请 / 学分以教师认定为准」

## 3. 申请表模板换成新上传的完整版并清干净示例
以新上传的《学生用：…申请表》为准（含"校级""非外语专业学生大学外语四、六级""第二课堂"等此前缺失的项目行），替换 `public/templates/申请表模板.xlsx`。

清理规则：
- 删除序号列里的"样例""1样例"字样
- 清空示例的成果名称、认定级别、本人排名、认定学分（如"**产业数字化转型策略研究 / 北大核心期刊 / 其他作者 / 6"等 6 处）
- 只有示例内容、没有项目名称的整行（第 7 行）整行清空
- 保留全部项目名称、四个大类标题、合计总学分、填写说明、审核栏与原有格式（含黄色底色去除）

同时同步更新表格解析逻辑的行定位，保证新模板能正确读取学生填写的条目。

## 4. 窗口结束后的学院统计表
按新上传的《学院用：…统计表》样式生成导出文件，列为：序号、学院、专业、班级、姓名、学号、认定总学分、认定成绩等级；底部保留系主任签名、分管院长签名、院部审核意见三行。

- 数据来源：该学院在本次申报窗口内已通过的申请，按学生汇总总学分，并按之前定的等级标准（≥7 优秀、6 良好、5 中等、4 及格、<4 不及格）填成绩等级
- 触发方式：学院/管理员在申报窗口管理页对已结束的窗口点击「生成统计表」下载

## 技术细节
- `src/pages/Index.tsx`（约 137 行）与 `src/pages/student/Apply.tsx`（约 280、289 行）改文案。
- 用 openpyxl 基于上传文件生成新的 `public/templates/申请表模板.xlsx`（清示例、去高亮），并相应调整 `src/lib/parseForm.ts` 的分类/表头识别。
- 统计表导出用 `xlsx` 在前端生成，数据取 `applications`（status=approved、窗口时间区间、college_id）聚合 `final_credit`，联表 `profiles` 取专业/班级/姓名/学号；沿用 `submission_windows` 页面入口。
