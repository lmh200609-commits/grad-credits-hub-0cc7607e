# 全流程演示与检查

用测试账号在本地预览里把「学生提交 → 教师审核 → 学分排名」完整走一遍，逐步截图并记录每一步是否正常。

## 演示步骤

1. 学生·白雪登录
   - 打开申请页，确认提交窗口显示为开放
   - 点击「下载空白模板」和「下载填写示例表」，确认两个文件都能下载且内容正确（示例表有样例、模板表干净）
2. 填表与上传
   - 用示例表内容生成一份测试申请表并上传
   - 确认解析出的条目（大类/项目/成果/级别/排名/学分）与表格一致
   - 确认每条的标准比对结果显示正常（符合 / 超标 / 偏低 / 待核对）
3. 佐证材料
   - 上传 2 张测试图片，确认预览、删除、重复图片拦截都生效
4. 提交
   - 提交后确认提示「提交成功，请等待教师审核」并跳转「我的申请」
   - 在「我的申请」里确认新记录状态正确
5. 教师·张老师登录
   - 打开待审列表，进入刚提交的申请详情
   - 确认能看到学生上传的原申请表预览、下载按钮、佐证图片、自报学分与标准学分比对
   - 填写最终认定学分并通过审核，确认状态更新
6. 学分排名页
   - 确认通过后的学分计入排名，数据显示正常

## 检查重点

- 窗口开放判断、模板/示例下载在预览环境是否都能触发
- 表格解析是否漏行或多解析抬头/说明行
- 图片查重（同批次 + 全库）是否误拦或漏拦
- 教师端原表预览是否正常渲染
- 审核通过后学分统计与排名是否同步

## 说明（技术）

- 使用 Playwright 无头浏览器访问 http://localhost:8080，按上述路径操作并截图。
- 演示会在数据库里产生一条真实的测试申请记录及附件文件；检查完成后可选择保留或删除该测试数据。
