# 修改密码入口 + 账号文件 + 全面检查

## 1. 右上角「修改密码」（管理员 / 教师 / 超管 / 学生都可用）
- 在右上角「退出」按钮旁加「修改密码」按钮，点开弹窗。
- 弹窗填写：**当前密码**、新密码、确认新密码。
- 防漏洞要求：
  - 必须先用当前密码验证身份，验证失败不允许改（防止别人用你没退出的电脑改密码）。
  - 新密码至少 8 位，且须同时含字母和数字；不能与当前密码相同；两次输入必须一致。
  - 连续输错当前密码有提示，按钮提交中禁止重复点击。
  - 改成功后提示「密码已修改，请重新登录」并自动退出。
  - 所有错误提示中文显示。
- 学生「我的档案」原改密功能同样补上「当前密码」校验，规则统一。

## 2. 账号密码文件
- 生成一个 Excel 文件《管理账号清单.xlsx》，含 5 个非学生账号：账号、姓名、角色、学院、当前密码 `O3Dx4MxQXJq1`，并附「首次登录后请立即修改密码」提醒。
- 文件放在你的「文件」区，不放进系统网站里（避免被别人下载）。

## 3. 运行测试
- 用后台密钥临时建一个测试管理员账号，实际登录 → 改密码 → 旧密码登录失败 / 新密码登录成功 → 错误当前密码被拒绝，测完删除该测试账号。
- 确认普通用户无法通过任何接口改别人的密码。

## 4. 全系统检查
- 检查构建错误、运行报错、网络请求失败。
- 用测试账号依次打开各角色主要页面（学生申请、我的申请、教师审核、学生管理、材料导出、批次、名录库、管理员账号），截图确认能正常打开、无报错。
- 跑一遍数据库安全检查，列出问题；明显的直接修，需要你决定的单独告诉你。
- 最后给你一份检查结果清单。
