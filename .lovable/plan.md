# 全面体检 + 学生首次登录完善个人信息

## 一、学生首次登录先完善资料（重点）
- 学生登录后，如果「姓名、班级、专业、身份证号、性别」任一为空，自动跳到「我的档案」，顶部提示「请先完善个人信息」，补全前其他页面（提交申请、我的申请等）暂不能进入。
- 五项全部必填并校验：
  - 姓名：导入账号时已必带，学生端保持只读不改
  - 身份证号：导入时不带，由学生首次填写；18 位并校验最后一位，性别与身份证第 17 位不一致时提示；保存后锁定，之后由教师/管理员修改
  - 性别：导入时可选带入；为空时学生用「男 / 女」下拉补填
  - 班级、专业：必填（导入已带则直接显示）
- 导入模板增加可选「身份证号」列，如学校有名单可直接导入，学生就不用再填。
- 院系、出生日期等其他字段保持选填（出生日期可由身份证号自动带出）。

## 二、资料同步到整个系统
- 所有信息只存一份（学生档案），教师端学生列表、班级学分、学分排名、审核详情、材料导出文件夹名（班级/学号-姓名）、学院统计表都实时读取这一份，学生改完即全系统一致，无需手动同步。
- 检查并修正仍在使用旧字段（如用「院系」代替「专业」）或缓存旧姓名的地方，统一以档案为准。
- 教师端学生列表增加「资料未完善」标记和筛选，导出统计表前可看到哪些学生资料缺失，汇总时空项会提示。

## 三、全面体检与冗余清理
1. 用学生、教师、管理员、超管四个测试账号逐页巡检，记录报错、空白页、权限问题，并修复。
2. 排查冗余：未被使用的页面/组件/后台函数（如开发测试用的 dev-seed、压力测试 ai-eval-stress-test、旧版关键词申请流程残留字段等），列出清单给你确认后再删除，不擅自删。
3. 检查完成后给你一份问题清单（已修复 / 待你决定 / 积压问题）。

## 积压问题（本次只提醒，不处理）
专业/班级导入错误、学时自动折算、赛事简称与校级档识别、AI 生成图概率判定方式（三选一未定）、数据库安全警告、测试数据清理。
