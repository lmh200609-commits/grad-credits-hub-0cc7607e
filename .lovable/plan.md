# 流程回归：下载模板填表 → 表格+佐证一起提交 → 系统只验真伪

学生下载学校标准《申请表》Excel 模板，线下自行填写、自行核算学分；提交时上传**填好的 Excel 表 + 佐证图片（逐个上传，不打压缩包）**。系统的职责收敛为三件事：**填报内容与佐证是否相符、是不是本人的材料、有没有 P 图/AI 生成造假**。

## 一、为什么不做压缩包（回答你的问题）

压缩包能做，但不推荐：
- 解压后文件命名混乱、嵌套文件夹会让"哪张图对应哪一行"难以匹配
- 压缩包损坏/超大导致整个提交失败
- 逐张单独上传，系统可以**逐行逐图比对**，核验准确率高，学生端体验也更直观（传完就能看到每张图的缩略图）

所以提交形式定为：**1 份填好的 Excel 申请表 + 若干张佐证图片**（每张图允许学生标注对应表内第几条，可选）。

## 二、要删 / 降级的（当前臃肿之处）

1. **学生端关键词四维选择器**（从案例库检索拼装 项目/成果/级别/身份）
   - 改为：学生不再选关键词，Excel 表格本身就是填报内容。取消关键词搜索、最近搜索、相似案例推荐、文案模板等区块。
2. **AI 建议学分 / 自动定学分**
   - 学分以学生在表内自填为准，AI 不再输出建议学分、不再按规则库匹配。教师复核时可手动改。旧字段保留，历史数据不丢。
3. **规则库 / 案例库 / 关键词库退出学生流程**
   - 三个库的表、分学院隔离、管理页全部保留，降级为**教师复核与 AI 判定的后台参考资料**，学生端不再读取。
4. **关键词指纹去重**失效 → 改为按「成果名称 + 认定项目」去重；图片仍按 `file_hash` 去重。

## 三、要改的

1. **学生提交页**（`src/pages/student/Apply.tsx`）重构为 2 步：
   - 第 1 步：下载模板（系统内置《学生用申请表》xlsx，一键下载）→ 线下填写
   - 第 2 步：上传填好的 Excel + 佐证图片（可多张，可拖拽），展示表格解析预览（每条一行：认定项目/成果名称/级别/排名/学分），确认无误后提交
   - 提交前自检提示："填报 X 条，合计 X 学分；佐证须与填报一致，弄虚作假按校规处理"
2. **AI 核验**（`supabase/functions/evaluate-application/index.ts`）改为逐条核验：
   - 用 SheetJS 解析 Excel，逐条取（认定项目/成果名称/认定级别/本人排名/认定学分）
   - 逐条与对应佐证图片比对：名称、级别、奖项、排名是否一致
   - 身份一致：佐证上的姓名/学号 vs 账号档案（防用他人证书）
   - 真实性：PS/拼接痕迹（AIGC 阿里云鉴别保持现状不动）
   - 输出：每条 通过/存疑/不符，整体结论 通过 / 驳回 / 需人工复核，**不再给学分**
   - 案例库仅作为"这类材料长什么样"的参照，不参与学分
3. **教师复核页**：按"条"展示核验结果（每条 ✅/⚠️/❌ + 原因），并排显示「学生自报学分 / 教师认定学分（可改）」；`final_credit` 默认取学生自报值。
4. **数据落库**：Excel 解析出的每一条存为一条 application 记录（沿用现有表、状态机、队列、AIGC 链路不变），新增字段存表格内容。

## 四、要加的

1. **数据库迁移（一条，只加列）**：`applications` 增加 `item_category`、`item_project`、`achievement_name`、`level_name`、`self_rank`、`claimed_credit`、`form_file_path`（上传的 Excel 原件）、`evidence_index`（对应第几张佐证，可空）。全可空带默认值，旧数据不受影响。
2. **模板下载**：把《学生用申请表》xlsx 放入 `public/templates/`，提交页提供下载按钮。
3. **Excel 解析**：前端用 SheetJS（`xlsx` 包）本地解析预览；边缘函数同样解析做核验。需 `bun add xlsx`。
4. **学院用统计表导出**：学院管理员/教师端按《学院用统计表》格式一键导出本院学生（学院/专业/班级/姓名/学号/认定总学分/等级）。

## 五、不动的部分

登录与角色、学院隔离、提交窗口、审计日志、证书编号与验真、AIGC 队列、AI 模型配置、导入用户、看板统计——全部保持原样。

## 技术说明

- 一条迁移：`ALTER TABLE public.applications ADD COLUMN ...`，无需改 RLS/GRANT。
- 前端：`Apply.tsx` 重写、`ApplicationDetail.tsx`/`Reviews.tsx` 展示新字段与逐条结论；新增 `src/lib/parseForm.ts`（表格解析）与 `src/lib/exportForms.ts`（统计表导出）。
- 边缘函数只改 `evaluate-application`（解析表格 + 逐条核验提示词）；`process-eval-queue`、`aigc-detect` 等不动。
- `cases`/`rules`/`keywords` 表与管理页零改动。
