# 赛事名录 + 证书名录：从历史统计表建库

## 我从你发的材料里读到什么

**竞赛类（2020-2025 十四五统计表，共 566 条 + 2019 级汇总表）**
- 赛事只有 32 个不同名称，反复出现的就那么十来个：数字贸易技能大赛（第四/五/六届，含外经贸单证、跨境电商、国际贸易赛道）、POCIB 全国外贸从业能力大赛、中国国际大学生创新大赛（"建行杯"互联网+）、挑战杯（课外学术科技作品 / 创业计划）、全国大学生电子商务"三创"挑战赛、三创赛、全国高校商业精英挑战赛、光华杯吉林省电子商务案例分析大赛、词达人 / 亿学杯英语类。
- 级别栏写法很乱：国家级A/B/C类、国家C类、省（部）级A类、省级A类、省部级A类、省级B类、校级、国际级C类，同一含义多种写法。
- 奖次也有多写法：一等奖 / 一等 / 国家级一等奖 / 特等奖 / 金银铜奖 / 最佳创意奖等。

**证书类（8 张统计表，约 670 条）**
- 实际只有 10 种证书名称：外经贸单证专业证书(395)、跨境电商交际英语结课证书(141)、阿里巴巴国际站操盘官(96)、助理国际贸易师专业能力证书(12)、会计专业技术资格·初级(8)、POCIB 国际贸易从业技能综合实训(6)、数字贸易职业能力（中级）证书(6)、阿里巴巴跨境电商人才初级证书(3)、教师资格(2)、社会体育指导员(1)。
- 你表里已有的"职业资格类型"字段是：专业技术人员职业资格 / 专业从业培训证书 / 其他 —— 和你说的分类口径基本一致。

## 要做的事

### 1. 赛事名录（管理员可编辑）
把上面 32 个赛事去重合并成约 15 条名录记录，每条带：标准名称、常见简称/别名（如"国创赛""互联网+""数贸赛""三创赛""POCIB"）、默认竞赛类别、默认级别档。
- 名称与别名做模糊匹配（数据库已装 pg_trgm，可直接用）。
- 匹配到 → 自动带出级别档，进入现有学分档位计算。
- 匹配不到 → 保持现状显示"待核对"，不阻止提交。

### 2. 级别写法归一 + C 类降档
建一张级别对照：
```text
国家级A类 / 国家A类        → 国家级A类
国家级B类 / 国家B类        → 国家级B类
国家级C类 / 国家C类 / 国际级C类 → 按省部级A类计分（降一档，你已确认）
省（部）级A类 / 省级A类 / 省部级A类 → 省部级A类
省级B类                   → 省部级B类
校级 / 院级                → 校级
```
奖次同样归一：特等/一等/金奖 → 一等；二等/银奖 → 二等；三等/铜奖/优秀奖 → 三等；最佳创意奖等非标准奖项 → 待核对。

### 3. 证书名录（三类 + 其他）
每条证书记录带：名称、别名、类别、默认学分档。类别为：
- **职业资格证书**——在《国家职业资格目录（2021）》内的（教师资格、会计专业技术资格初级、社会体育指导员等）
- **从业资格证书（行业资格）**——目录外、与专业相关的（外经贸单证专业证书、助理国际贸易师、数字贸易职业能力中级、POCIB 合格证书）
- **专业从业培训证书**——培训/结课性质（跨境电商交际英语结课证书、阿里巴巴国际站操盘官、阿里巴巴跨境电商人才初级）
- **其他（自填）**——学生自己填名称、发证单位、时间、等级，系统不猜分，直接标"待核对"交老师人工看

### 4. 学生端「其他」自填项
申请表新增"其他"这一项目类型（文体比赛、校院级随机赛事、名录外证书都走这里）。学生填名称+级别+奖次/等级+发证单位即可，学分栏可留空，提交后统一显示"待核对"。学生端不出现"人工复核""AI 复核"字样。

### 5. 教师端
名录匹配结果、级别归一后的档位、以及"为什么待核对"的具体原因，只在教师端详情页显示。教师仍可覆盖。

## 技术要点

- 新增两张表 `competition_catalog`、`certificate_catalog`（名称、别名数组、类别、级别档、默认学分、是否启用、college_id、启用/停用），RLS：教师和学生只读、管理员可写；随 `clone_template_to_college` 一起给新学院播种。
- 用历史统计表的数据做种子数据导入（去重后约 15 条赛事 + 10 条证书 + 目录关键词）。
- `src/lib/creditStandard.ts` 增加级别归一函数 `normalizeLevel()`、奖次归一 `normalizePrize()`，并在竞赛/证书分支前先查名录。
- 管理员后台新增两个页面：`/admin/competitions`、`/admin/certificates`，支持增删改、别名编辑、搜索、批量启停。
- 现有 `certificate_types`（131 行，自动从案例库同步）保持不动，新名录是人工维护的权威表，匹配时名录优先。
