# 修复申请表模板下载问题

## 检查结论
- 当前项目里两个模板文件都在，内容完整，代码下载路径也正确。
- 已发布网址返回「文件不存在」(404)：原因是发布出去的是旧版本，模板文件是之后才放进去的，发布后没有点「更新」。
- 学校服务器隐患：文件名是中文，部分服务器对中文路径处理不稳定；另外如果文件没放对位置，学校服务器会把首页内容当成表格下载下来，得到一个打不开的「空文件」。这就是之前学生说「下载了没有内容」的原因。

## 要做的修改
1. 把两个模板文件改成英文文件名（`application-template.xlsx`、`application-sample.xlsx`），下载时学生拿到的文件名仍是中文正规名称，不受影响。
2. 下载前检查拿到的是不是真正的表格文件；不是的话提示「模板文件缺失，请联系管理员」，不再下载出空文件。
3. 修改后实际测试预览里的两个下载按钮，确认下载的表格能打开、内容完整。
4. 重新发布在线网址，并再次测试在线下载。
5. 给出学校服务器的更新步骤（1Panel 内操作）：把新的 `templates` 文件夹里两个英文名文件上传到 `/opt/1panel/www/sites/localhost/index/templates/`，并覆盖网页文件；附在浏览器直接打开模板地址的检查方法。

## 回答您的问题
更新版本后可以正常下载，前提是 `templates` 文件夹和里面两个文件一起上传到网站目录。
