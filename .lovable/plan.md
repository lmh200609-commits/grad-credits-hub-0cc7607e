# 流程回归：下载模板填表 → 表格+多张佐证一起提交 → 系统只验真伪

学生下载**系统提供的干净空白模板**（从学校《申请表》剔除「样例」示例行，保留四大类结构、列头和填写说明），线下自行填写、自行核算学分；提交时上传**填好的 Excel 表 + 多张佐证图片（逐张上传，不打压缩包）**。系统职责收敛为三件事：**填报内容与佐证是否相符、是不是本人的材料、有没有 P 图/AI 生成造假**。解析时自动忽略任何含「样例」字样的行，学生即使保留了示例也不会污染数据。

## 一、关于压缩包与表格识别（先回答疑问）

- **不用压缩包**。压缩包解压后文件命名/嵌套混乱，难以定位"哪张图对应哪一条"，且损坏即整单失败。改为**表格 1 份 + 佐证图片多张逐张上传**，系统可逐行逐图比对，学生也能即时看到缩略图。
- **表格能准确读取**。Excel 是结构化文件，用 SheetJS 直接取单元格原文，不是 OCR，无识别误差。风险只在学生擅改模板结构，故上传后先做**解析预览 + 结构校验**，不符合模板则提示重新下载模板填写。
- **多图支持**：单次最多 20 张，单张 ≤10MB，支持拖拽批量上传、删除、排序；每张可选择"对应表格第几条"。

## 二、要删 / 降级的（当前臃肿之处）

1. **学生端关键词四维选择器**（从案例库检索拼装 项目/成果/级别/身份）——取消关键词搜索、最近搜索、相似案例推荐、文案模板等区块。
2. **AI 建议学分 / 自动定学分**——学分以学生表内自填为准，AI 不再输出建议学分，教师复核时可改。旧字段保留，历史数据不丢。
3. **规则库 / 案例库 / 关键词库退出学生流程**——表、分学院隔离、管理页全部保留，降级为教师复核与 AI 判定的后台参考资料。
4. **关键词指纹去重**失效 → 改为按「成果名称 + 认定项目」去重；图片仍按 `file_hash` 去重。

## 三、要改的

1. **学生提交页**（`src/pages/student/Apply.tsx`）重构为 2 步：
   - 第 1 步：一键下载模板 → 线下填写
   - 第 2 步：上传填好的 Excel + 批量上传佐证图片 → 展示解析预览（每条：认定项目/成果名称/级别/排名/学分）与图片缩略图 → 确认提交
   - 提交前自检提示："共 X 条、合计 X 学分、X 张佐证；材料须与填报一致，弄虚作假按校规处理"
2. **AI 核验**（`supabase/functions/evaluate-application/index.ts`）改为逐条核验：
   - 解析 Excel 逐条取（认定项目/成果名称/认定级别/本人排名/认定学分）
   - 逐条与其佐证图片比对：名称、级别、奖项、排名是否一致
   - 身份一致：佐证上的姓名/学号 vs 账号档案（防用他人证书）
   - 真实性：PS/拼接痕迹；AIGC 阿里云鉴别链路保持不动
   - 输出每条 通过/存疑/不符 + 整体结论（通过 / 驳回 / 需人工复核），**不再给学分**
3. **教师端 / 管理端详情查看**（`ApplicationDetail.tsx`、`Reviews.tsx`、`teacher/Students.tsx`）：
   - 详情页展示：学生档案（姓名/学号/专业/班级）、表格逐条内容、每条对应佐证的**原图**（点击放大、可下载原文件）、原始 Excel 可下载与在线预览
   - 逐条核验结论（✅/⚠️/❌ + 中文原因），并排「学生自报学分 / 教师认定学分（可改）」
4. **按班级检索与分类**：
   - 复核列表、学生列表、提交记录页新增「专业 / 班级」筛选下拉 + 关键字搜索（姓名/学号）
   - 列表支持按班级分组统计（该班提交数、通过数、总学分）

## 四、要加的

1. **数据库迁移（只加列 + 一张附件表）**：
   - `applications` 增列：`item_category`、`item_project`、`achievement_name`、`level_name`、`self_rank`、`claimed_credit`、`form_file_path`
   - 新建 `application_attachments`（application_id、file_path、file_hash、order_index、note），支持一条申请多张佐证；含 GRANT + RLS（学生只读写自己的，教师/管理员按学院读）
2. **模板下载**：《学生用申请表》xlsx 放入 `public/templates/`，提交页提供下载按钮。
3. **Excel 解析**：前端与边缘函数均用 SheetJS（`bun add xlsx`）。
4. **学院用统计表导出**：按《学院用统计表》格式导出本院学生（学院/专业/班级/姓名/学号/认定总学分/等级），支持按班级导出。

## 五、不动的部分

登录与角色、学院隔离、提交窗口、审计日志、证书编号与验真、AIGC 队列、AI 模型配置、导入用户、看板统计——全部保持原样。

## 技术说明

- 迁移：`ALTER TABLE public.applications ADD COLUMN ...` + `CREATE TABLE public.application_attachments`（含 GRANT / RLS / updated_at 触发器）。
- 前端：重写 `Apply.tsx`；`ApplicationDetail.tsx` 增加原图画廊与表格预览；`Reviews.tsx`、`teacher/Students.tsx`、`SubmissionRecords.tsx` 增加班级筛选；新增 `src/lib/parseForm.ts`、`src/lib/exportForms.ts`。
- 班级数据来源 `profiles.class_name` / `major`，已存在，无需新增字段。
- 边缘函数只改 `evaluate-application`（解析表格 + 多图逐条核验）；`process-eval-queue`、`aigc-detect` 等不动。
- `cases`/`rules`/`keywords` 表与管理页零改动。
