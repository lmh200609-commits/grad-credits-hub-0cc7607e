# 提交页改成两个填报模块 + 系统改名 + 修好模板下载

## 1. 申请表模块（弹窗填报）
- 学生点「填写申请表」会弹出一个窗口，学号自动带出（不能改），标题固定是「创新实践学分认定申请表」。
- 在弹窗里上传 Excel 申请表，系统照旧读取表里的内容。
- 系统按统一格式保存文件名：`学号-创新实践学分认定申请表.xlsx`，学生电脑上原来的文件名不用。

## 2. 佐证材料模块（一条一条新增）
- 点「新增佐证」会弹出窗口，填三项：学号（自动带出）、证书名称、认定学分，再上传 1 份 PDF。
- 保存后这条佐证会出现在列表里，可以修改或删除；再点「新增佐证」添加下一份，最多 20 份。
- 每份文件按统一格式命名：`学号-证书名-认定学分.pdf`，例如 `2024001-助理国际贸易师-2分.pdf`。证书名里的非法字符会自动替换掉。
- 原有的 PDF 限制都保留：只收 PDF、每份不超过 10MB、同一份文件不能重复交、PDF 照样转成图片做自动核对。

## 3. 导出也用统一文件名
- 「材料导出」压缩包里的文件名改成上面两种格式，不再叫「申请表.xlsx」「佐证材料1.pdf」。
- 老师打开申请详情时，佐证列表显示证书名和认定学分。

## 4. 系统统一改名为「本科生创新实践学分认定系统」
- 登录页、浏览器标签、左侧栏、顶栏、助手说明里的「学分认证系统」全部替换。
- 新建学院时默认名称也改成这个；已有学院里存的旧名称一并改掉。

## 5. 两个模板下载修好
- 用你上传的两份文件替换系统里的模板：「学生用」那份作为空白模板，「样例」那份作为填写示例。
- 学生下载后能看到完整内容；下载时的文件名也改成统一的名称。

## 技术说明
- 数据库：`application_attachments` 增加 `cert_name text`、`claimed_credit numeric`；存储路径仍用安全的英文/数字路径，规范后的中文名存到 `file_name`，下载和导出时使用。`submit_application` 函数同时写入这两个新字段。用一次性 SQL 把 `colleges.system_title` 的旧默认值改成新名称。
- 前端：`Apply.tsx` 拆成两个 Dialog（申请表、佐证条目）；`WindowExport.tsx` 的 `buildTasks` 改用规范文件名，同名时加 (2)；`AttachmentsGallery`/`ApplicationDetail` 显示证书名和学分；`index.html`、`Login.tsx`、`AppLayout.tsx`、`Colleges.tsx` 和两个助手函数里的名称替换。
- 模板：把上传的两份 xlsx 复制到 `public/templates/` 覆盖原文件，并检查解析逻辑能识别新模板的表头。
- 学校服务器要同步：这次需要更新网页文件，运行一段数据库补丁，并更新两个后台助手函数。
